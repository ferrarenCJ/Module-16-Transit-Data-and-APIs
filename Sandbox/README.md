# Sandbox

## Overview

This folder contains experimental code, testing notebooks, prototype scripts, and temporary files created while working through Module 16: Transit Data and APIs.

The sandbox environment provides a safe location for testing ideas, troubleshooting issues, validating API responses, and experimenting with technologies used throughout the module.

---

## Purpose

The Sandbox folder was used to:

- Test MBTA API calls
- Explore JSON response structures
- Validate database connections
- Experiment with Docker commands
- Test Mapbox functionality
- Verify MongoDB queries
- Prototype Jupyter Notebook analysis
- Debug project issues before implementing production changes
