# Module 16 Glossary

## curl
**Definition:**  
curl is a command-line tool used to transfer data to or from a server.

---

## Internet Protocol (IP)
**Definition:**  
An internet protocol is a set of rules governing the format of data sent over the internet or other networks. Internet protocols work with IP addresses to ensure information is transmitted correctly across a network.

---

## Layers
**Definition:**  
One feature of Mapbox is layers. Layers add complexity and customization to maps, creating a more interactive experience. For example, layers can highlight streets, colorize buildings, or identify parks.

---

## Location-Based Applications/Services
**Definition:**  
Location-based applications or services use the geographical location of a device to provide relevant information or functionality. Examples include Google Maps and Uber.

---

## Mapbox
**Definition:**  
Mapbox is a JavaScript web client library that enables developers to build web applications with customizable maps.

---

## Map Marker
**Definition:**  
A map marker is a symbol used to identify a specific location on a map.

---

## Maven
**Definition:**  
Apache Maven is a project management and build automation tool commonly used by Java developers. Maven helps manage dependencies, organize project structures, and simplify software builds.

---

## MBTA API
**Definition:**  
The MBTA API is an application programming interface provided by the Massachusetts Bay Transportation Authority (MBTA) that delivers schedules, alerts, and real-time transit information.

---

## Project Object Model (POM) File
**Definition:**  
A Project Object Model (POM) file is the primary configuration file used by Maven. It stores project information, dependencies, plugins, and build settings, allowing Maven to manage a project efficiently.

---

## Proxy
**Definition:**  
A proxy server is an intermediary system that sits between a client and a server. Proxy servers are commonly used for security, filtering, monitoring, and firewall implementations.

---

## Styles
**Definition:**  
In Mapbox, styles define the visual appearance of a map, including colors, shapes, labels, roads, buildings, and other geographic features.

---

## Transit Data Application
**Definition:**  
A transit data application is an application that processes and displays transportation data that is actively changing or moving between locations, often using real-time updates.

---

## Vector Tiles
**Definition:**  
A vector tile is a lightweight data format used by Mapbox to store geographic vector data such as points, lines, and polygons for efficient map rendering.

---

## Web Client Library
**Definition:**  
A web client library is a collection of reusable code that developers can integrate into applications. Mapbox is an example of a web client library that provides mapping functionality.
