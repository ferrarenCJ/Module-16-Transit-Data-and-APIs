# Module 16: Transit Data and APIs

## Module Objectives

- Describe use cases of location-based applications
- Identify web development tools used in application development
- Understand Mapbox capabilities
- Consume REST APIs
- Use curl for API interaction
- Build a transit data application
- Store transit data in MySQL
- Implement CDC using Debezium
- Replicate data to MongoDB
- Perform analysis on collected transit data
