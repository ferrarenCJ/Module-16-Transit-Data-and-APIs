# Project 16.1: Build a Transit Data Application

## Overview

This project demonstrates the design and implementation of an end-to-end transit data pipeline using real-time MBTA Route 1 data. The solution integrates API data collection, relational and NoSQL databases, containerization, Change Data Capture (CDC), geospatial visualization, and data analytics.

The application continuously collects live vehicle location data from the MBTA API, stores the data in MySQL, replicates changes to MongoDB using Debezium CDC, displays bus locations using Mapbox, and performs historical analysis using Jupyter Notebooks.
