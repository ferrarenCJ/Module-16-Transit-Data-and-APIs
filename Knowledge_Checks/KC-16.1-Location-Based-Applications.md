✅ **Answer:** Flask

## Question 2

### Which of the following is the correct syntax to create an instance of a web application in Python using Flask?

✅ **Answer:** app = Flask(__name__)

**Explanation:**  
A Flask application is created by instantiating the `Flask` class and passing `__name__` as the argument.

```python
from flask import Flask

app = Flask(__name__)
```

## Question 4

### What is the decorator that is used to define the route of a web application?

✅ **Answer:** @app.route('/')

**Explanation:**  
The `@app.route()` decorator maps a URL to a Python function.

```python
@app.route('/')
def home():
    return "Hello World"
```

## Question 5

### What is curl?

✅ **Answer:** curl is a command line tool used for transferring data to or from a server.

**Explanation:**  
Curl is commonly used to:

- Test APIs
- Download files
- Retrieve web content
- Transfer data between clients and servers

Example:

```bash
curl https://api-v3.mbta.com/vehicles
```
