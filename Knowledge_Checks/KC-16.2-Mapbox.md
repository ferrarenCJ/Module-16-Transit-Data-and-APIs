## Question 2

### Which feature can you add to your map by using the Mapbox `.addTo(map)` function?

✅ **Answer:** Markers

**Explanation:**  
The `.addTo(map)` function is commonly used when creating map markers.

```javascript
new mapboxgl.Marker()
    .setLngLat([-71.104081, 42.365554])
    .addTo(map);
```

## Question 3

### Which of these features does Mapbox include?

✅ **Answer:** Vector tiles

**Explanation:**  
Vector tiles are a built-in Mapbox feature used to efficiently store and render geospatial data, including:

- Roads
- Parks
- Buildings
- Boundaries

### Which of the following is not something you can do in Mapbox?

✅ **Answer:** Set the color of the sky to a shade of blue.

**Explanation:**  
Mapbox layers can be used to:

- Highlight roads
- Color buildings

- Customize geographic features

However, based on the lesson content, Mapbox layers cannot be used to change the color of the sky.
