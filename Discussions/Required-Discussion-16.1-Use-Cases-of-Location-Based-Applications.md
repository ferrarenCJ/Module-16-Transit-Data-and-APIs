# Required Discussion 16.1: Use Cases of Location-Based Applications

One location-based service (LBS) I use frequently is **Uber**. Uber relies on GPS data to connect riders with drivers and provide navigation.

A major privacy risk is that location history can reveal where people live, work, and travel. During an active ride, Uber should update location frequently for accurate tracking, but when the app is not in use, location requests should be limited. Users should also be able to disable location sharing or allow it only while using the app.

Location history should primarily be accessible to the user and authorized company personnel. Any sharing with third parties should require clear user consent. I would not sell user location data because user privacy and trust are more important than generating additional revenue.

Uber could be improved by providing more transparent privacy controls and limiting how long location data is retained.

An example of an app that should not require location access is a flashlight or calculator app. I have encountered utility apps that requested my location despite having no obvious need for it. When this happens, I usually deny the request because the purpose of collecting that information is unclear.
